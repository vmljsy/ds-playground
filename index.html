Foundations & Architecture

Engineered for clarity, deterministic math, and direct browser execution.

Standard Sampling Algorithms

Random variates use exact mathematical routines: Box-Muller transforms for Gaussian normals, Knuth's algorithm for Poisson processes, and Jöhnk's rejection method for Beta distributions.

Pure Client-Side Computation

Zero backend servers, zero telemetry, and zero rate limits. Computations execute in your browser's JavaScript engine at 60 frames per second using Plotly.js and KaTeX.

Modular ES6 Structure

Every experiment is an isolated ES module exporting an init() function. Contributions require only standard HTML and vanilla JavaScript—no build step or bundler needed.
